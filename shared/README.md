# shared

The contract every folder codes against. Only the head changes these files.

| File | What it is |
|---|---|
| `openapi.yaml` | All endpoints, request and response shapes |
| `ports.md` | Ports, environment variables, timings |
| `errors.md` | Error format and codes |

Need a change? Open an Issue with the tag `[shared]` and say what you need and why.

View the API in a browser: paste `openapi.yaml` into https://editor.swagger.io
