## About Kamui Cloud

Kamui Cloud aims to provide a unified private cloud platform for managing computing resources and services across connected machines on a local network.

The planned platform includes components for node management, storage, workload execution, machine-learning training, inference, file sharing, a command-line interface, and a web console.

The implementation is under development. Refer to the actual source code and tests to determine which features are currently available.
